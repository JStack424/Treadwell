# Treadwell

Build roads worth taking.

This package was generated from the JStack424 Valheim mod template. The starter feature is intentionally disabled and changes no gameplay until implemented.

## Installation

Install with r2modman or Thunderstore Mod Manager. This is a client-side BepInEx 5 plugin unless the implemented feature documents otherwise.

## Safety

The plugin validates the exact supported Valheim, Unity, BepInEx, Harmony, and `assembly_valheim` runtime before installing feature hooks. An unverified update disables the mod rather than guessing.
